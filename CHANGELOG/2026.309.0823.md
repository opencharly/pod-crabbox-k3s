# 2026.309.0823 — feat(image): advance the base to pod-crabbox-nested 2026.309.0812

Advances this image's base from `pod-crabbox-nested:2026.309.0149` to `:2026.309.0812`, which carries the inner containerd configuration that makes this image's k3s CNI drop-in effective. Producer-first: the nested change merged and tagged before this bump, and the published image at that tag was confirmed in the registry before the base line was touched.

## Summary

The `k3s-lease` candy writes `/etc/containerd/conf.d/50-k3s-cni.toml` carrying k3s's two CNI directory keys. Until now nothing read it: the inherited image had **no `/etc/containerd/config.toml`** and its inner containerd unit passes no `--config`, so containerd ran on built-in defaults with an empty `imports` list, and the drop-in was inert. That gap is `opencharly/pod-crabbox-k3s#2`.
